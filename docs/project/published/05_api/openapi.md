# Спецификация OpenAPI

[Открыть Swagger UI](../assets/swagger/index.html){ .md-button .md-button--primary }

[Скачать OpenAPI YAML](openapi.yaml){ download="openapi.yaml" }

Спецификация OpenAPI 3.0.3 содержит операции клиентского API, параметры, запросы, ответы и схемы данных.

Метки: `x-release` — MVP или первый релиз R1; `x-stories` — связанные истории; `x-roles` — разрешенные роли и типы клиентов. Расширения R1 в операциях MVP отмечены отдельно.

Связанные разделы: [назначение операций и общие правила](resources.md), [экраны и вызовы API](ui.md), [контракты внешних адаптеров](adapter-contracts.md).
