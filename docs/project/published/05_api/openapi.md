# Спецификация OpenAPI

[Открыть Swagger UI](../assets/swagger/index.html){ .md-button .md-button--primary }

[Скачать OpenAPI YAML](openapi.yaml){ download="openapi.yaml" }

В Swagger UI доступны поиск операций, параметры, тела запросов, ответы и схемы данных. Русский текст отображается в UTF-8. Просмотр использует ту же спецификацию, что и YAML; отдельный контракт не ведется.

Контракт OpenAPI 3.0.3 описывает клиентский API приложения. `x-release: MVP` обозначает первую жизнеспособную версию, `x-release: R1` — первый релиз после MVP. Если операция MVP содержит расширение R1, оно отдельно отмечено в описании и схемах. `x-stories` связывает операцию с историями, `x-roles` определяет роли и типы клиентов.

Бизнесовое назначение, права и единые правила повторов приведены в [ресурсах API](resources.md). Переходы экранов и обработка ответов описаны в [UI](ui.md). Требования к сообщениям внешних адаптеров вынесены в [отдельный контракт](adapter-contracts.md). Он требует подтверждения поставщиками.

В спецификации разделены покупка, попытка оплаты, возврат и документы. Оплата начинается только после сохраненного расчета и резерва. Неизвестный результат не разрешает новый платеж. Код талона отсутствует в ответах клиентам. Клиент не задает статус заказа и не рассчитывает сумму к списанию.
