# Ограничения и допущения

## Проверка допущений

Продуктовые правила используются в этой версии требований. Технические допущения A-02/03/05/08/14 должны быть проверены по возможностям оборудования и внешних систем на этапе 2. Если они не выполняются, требуется изменение решения или границ пилота. Параметры A-06 проверяются расчетами и испытаниями; они не объявляются свойствами существующей системы.
