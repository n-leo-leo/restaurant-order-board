# Тест-кейсы MVP

Приемочные испытания MVP **не выполнялись**. Все кейсы обязательны. P0 охватывает оплату, сохранность данных и безопасную выдачу. P1 — остальные проверки.

## Общие условия

На изолированном стенде работают четыре киоска и табло. Для каждой роли есть личная учетная запись. Вызовы адаптеров склада, банка, кухни, кассы и принтера записываются. По умолчанию ресторан R1 и торговый день D1 открыты. Платежи тестовые. Перед каждым независимым прогоном восстанавливают исходные данные. На стенде можно менять время и воспроизводить сбои. Часы источников событий синхронизированы. Проверяют экран, ответы API, сохраненные данные и журнал вызовов. Доступ проверяющего к данным не меняет права пользователей.

Денежные примеры показаны в рублях; в API передаются целые копейки RUB. Устройства и контроль пустоты сначала проверяются по реестру допущений. Имитаторы подходят для логики, приемка реального оборудования требует отдельного протокола. Для каждого выполнения сохраняются сборка, окружение, дата, исполнитель, фактический результат каждого шага, доказательства и дефекты.

Порядок восстановления и повторов — [API](../05_api/resources.md#retries); правила — [допущения](../02_requirements/assumptions.md); переходы — [модель состояний](../03_model/order-states.md). Общая подготовка входит в предусловия каждого кейса.
