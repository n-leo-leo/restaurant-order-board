## Как применять реестр

По получении ответа обновляются статус допущения, связанная история, AC, процесс и НФТ. Даты и источник подтверждения фиксируются в журнале решений. До этого зависимые варианты используются только в рабочей документации и не обозначаются как согласованные преподавателем.
