# Обзор вариантов использования

Основной формат требований — [User Story](user-stories.md), согласованный для проекта. Ниже — обзор участников и возможностей, без дублирования полного описания историй.

| Участник | Варианты использования | Релиз |
|---|---|---|
| Посетитель | Меню, карточка блюда, корзина, тип обслуживания, бизнес-ланч, оплата картой, талон, табло, получение и помощь | MVP |
| Посетитель | Регистрация/вход, бонусы, наличные, подарок | Первый релиз |
| Менеджер гостеприимства | Уведомление о проблеме, ручная помощь и возврат через внешние средства | MVP, A-03 |
| Менеджер гостеприимства | Поиск, отмена/возврат и уведомления в интерфейсе | Первый релиз |
| Менеджер по ассортименту / технолог | Меню, цены, акции, комбо готовых блюд и техкарты | Первый релиз |
| Сотрудник производства | Мониторинг и сведения о пополнении | Первый релиз; внешний монитор в MVP — A-05 |
| Аналитик ресторана | Отчеты о продажах и возвратах, выгрузка 1С | Первый релиз |

Обзорная диаграмма из ДЗ 06 пока не перенесена: основным форматом выбраны User Story, а обзор участников приведен в таблице. Это вспомогательный материал, а не замена карте историй. Подробные Use Case вместо User Story не разрабатываются.
