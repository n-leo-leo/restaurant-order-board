# Приложение для заказа + табло

Проектная работа курса «Системный аналитик». Кейс: автоматизированный ресторан «Робот и точка».

## О проекте

- **Объект проектирования:** приложение для заказа блюд в киоске самообслуживания и табло выдачи заказов.
- **MVP:** заказ в киоске (меню → корзина → тип обслуживания → оплата картой → талон) + табло выдачи + передача заказа роботам.
- **Вне рамок MVP:** мобильное приложение, конструктор комбобургера.
- **Подход к требованиям:** User Story.
