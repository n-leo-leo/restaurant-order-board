## Ответ преподавателя и дальнейшие решения

Преподаватель ознакомился со структурой и подтвердил ее. По продуктовым вопросам разрешено самостоятельно проектировать систему, фиксируя ограничения и допущения; отдельно рекомендовано сосредоточиться на жизнеспособном MVP. Конкретное содержимое этапа этим ответом не согласовано.

В рамках этого подхода применены правила [A-01–A-14](02_requirements/assumptions.md). Для MVP выбраны минимальный экран помощи менеджеру, ручной возврат внешними средствами, фиксированные правила бизнес-ланча, условная регистрация выдачи по открытию ячейки и ручная проверка ее освобождения. Полноценная админка, собственный монитор производства, лояльность, наличные и подарок не добавляются в MVP.

Технические возможности внешних систем не объявлены установленными фактами: атомарный резерв, монитор роботов и средства возврата — допущения, проверяемые на этапе 2. Полное согласование содержимого этапа остается открытым.

## Финальная проверка этапа 1

Устранены расхождения минимального/полного интерфейса менеджера и освобождения ячеек. Дополнен путь оплаты: идентификатор покупки сохраняется до эквайринга, неизвестный результат не сбрасывается по таймеру, повторная доставка не создает второго логического задания роботу. Добавлены БТ-18/US-35 и A-14 для чека и сбоя его выдачи; кассовая интеграция уже входила в MVP. Срок хранения готовой порции не возобновляется при скрытии номера. Базовые правила функций первого релиза зафиксированы без добавления их в MVP.

Содержимое локально проверено и готово к отправке; преподаватель пока подтвердил только структуру. Подробный отчет — `docs/project/07_Финальная_проверка_этапа_1.md`, на сайт он не копируется.

## Изменение A-02: контроль по весу

Автор согласовал автоматическую проверку пустоты по весу после закрытия дверцы. Это заменяет решение об условной выдаче по одному открытию и обязательной ручной проверке каждой ячейки. Сотрудник остается для неявки, остатков, очистки и сбоев. Наличие датчиков, калибровка, допустимый диапазон, стабилизация и тайм-аут — проверяемые технические допущения этапа 2, а не уже подтвержденные свойства оборудования.
