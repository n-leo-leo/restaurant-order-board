# Решения и допущения

Решения, принятые при подготовке проекта, и их обоснование.

| № | Решение | Обоснование | Статус |
|---|---|---|---|
| 1 | MVP = приложение для заказа в киоске + табло выдачи заказа. Мобильное приложение в MVP не входит | Противоречие в протоколах: Product Owner — мобильное приложение (протокол 1, №12), CTO — мобильное приложение не входит в MVP (протокол 3, №16). Макеты и архитектура выполнены под киоск | Согласовано с преподавателем 09.11.2026 |
| 2 | Конструктор комбобургера в MVP не включаем. Комбо-наборы из готовых блюд остаются | Ограничение технолога: на текущем этапе клиент не может менять конфигурацию блюда (протокол 2, №10) | Согласовано с преподавателем 09.11.2026 |
| 3 | Требования описываются через User Story. Диаграмма Use Case — обзорная схема | Достаточно одного формата представления требований | Согласовано с преподавателем 09.11.2026 |
