# Домашнее задание
## Декомпозиция и критерии

### Цель

Отработать навыки декомпозиции пользовательских историй и формулирования критериев приёмки для чёткой постановки задач разработчикам.

---

### Описание / пошаговая инструкция выполнения

Необходимо:

1. Выбрать одну из историй, описанных в рамках ДЗ по User Story, и предложить минимум три варианта её декомпозиции.
2. Выбрать минимум 4 истории, описанных в рамках ДЗ по User Story, и для каждой описать минимум три Acceptance Criteria.
3. Для каждой истории из пункта 2 подготовить минимум три задачи для разработчиков, приложив макет интерфейса и описав необходимые для реализации поля и функции.

Задание выполняется индивидуально.

---

### Критерии оценки

1. Подготовлено минимум три варианта декомпозиции пользовательской истории.
2. В каждом варианте истории более низкого уровня по-прежнему сохраняют ценность для пользователя.
3. Для 4 историй подготовлено минимум 12 Acceptance Criteria (по три на каждую).
4. Каждый Acceptance Criteria содержит информацию о контексте, выполняемом действии и ожидаемом результате.
5. Для 4 историй подготовлено минимум 12 задач для разработчиков (по три на каждую).
6. Каждая задача описана конкретно, однозначно и может быть оценена разработчиком.

Статус **«Принято»** ставится при соблюдении всех критериев.
