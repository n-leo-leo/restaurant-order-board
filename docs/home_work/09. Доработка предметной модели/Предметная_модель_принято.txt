' Каталог
Меню "1" o-- "0..*" Категория : агрегирует
Категория "1" o-- "0..*" Товар : группирует
Товар "1" *-- "0..*" Фото_товара : содержит

' Комбо из готовых товаров (M:N без связующей сущности)
Комбо_товар "0..*" o-- "1..*" Товар : включает

' Заказ — частный случай корзины (генерализация)
Корзина <|-- Заказ
Клиент "0..1" --> "0..*" Корзина : формирует
Клиент "0..1" --> "0..*" Заказ : делает
Корзина "1" *-- "1..*" Позиция_корзины : содержит
Позиция_корзины "0..*" --> "0..1" Товар : выбранный_товар
Позиция_корзины "0..*" --> "0..1" Комбо_товар : выбранный_комбо
Позиция_корзины "0..*" --> "0..1" Комбо_бургер : выбранный_бургер

' Оплата (UC 3)
Заказ "1" *-- "0..1" Оплата : имеет
Оплата "1" *-- "1..*" Платежная_операция : состоит_из
Оплата "1" *-- "0..1" Чек : формирует
Платежная_операция "1" *-- "0..1" Подтверждение : требует

' Бонусы
Клиент "1" *-- "0..1" Бонусный_счет : имеет
Бонусный_счет "1" *-- "0..*" Бонусный_пакет : содержит
Бонусный_счет "1" *-- "0..*" Бонусная_операция : фиксирует
Заказ "0..1" --> "0..*" Бонусная_операция : основание

' Комбобургер
Комбо_бургер "0..*" o-- "1..*" Ингредиент : состоит_из
Комбо_бургер "0..*" ..> "0..*" Правило_наценки_комбо : рассчитывается_по
