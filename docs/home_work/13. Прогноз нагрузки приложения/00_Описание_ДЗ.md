# Домашнее задание  
## Прогноз нагрузки приложения

### Цель

Рассчитать нагрузку на приложение при запуске и спрогнозировать её прирост через 1, 3 и 5 лет для обоснования выбора базы данных и требований к производительности.

---

### Описание / пошаговая инструкция выполнения

Необходимо:

1. Определить нагрузку на приложение на момент запуска в соответствии с алгоритмом, приведённым на занятии.
2. Составить прогноз по приросту нагрузки через 1 год / 3 года / 5 лет с обоснованием прироста:
   - указать требования к производительности;
   - рассчитать первичную нагрузку;
   - рассчитать количество пользователей;
   - рассчитать нагрузку на систему с учётом пользователей из п. 3;
   - рассчитать размер БД;
   - сделать выбор БД.

Задание выполняется индивидуально и сдаётся в виде Excel-файла или ссылки на Google-таблицу с описанием прогноза нагрузки.

---

### Критерии оценки

1. Подготовлен прогноз нагрузки на момент запуска приложения.
2. Подготовлен прогноз нагрузки через 1 год. Приведено обоснование.
3. Подготовлен прогноз нагрузки через 3 года. Приведено обоснование.
4. Подготовлен прогноз нагрузки через 5 лет. Приведено обоснование.

Статус **«Принято»** ставится при соблюдении всех критериев.
