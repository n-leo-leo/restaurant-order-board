# Домашнее задание

## Работа с данными в Excel

### Цель

Отработать навыки извлечения и визуализации данных через SQL, Power Query и Excel для анализа бизнес-информации.

---

### Описание / пошаговая инструкция выполнения

Необходимо:

1. Подготовить SQL-запросы согласно заданию.
2. Подключиться к БД с помощью Power Query.
3. Подтянуть ранее составленные SQL-запросы в Excel с помощью Power Query.
4. Визуализировать полученные данные.
5. Сделать выводы.

Задание выполняется индивидуально и сдаётся в формате Excel.

---

### Критерии оценки

1. Подготовлены все запросы и визуализации.
2. Для каждой визуализации сделан соответствующий вывод.

Статус **«Принято»** ставится при соблюдении всех критериев.

---

## Уточнение от преподавателя (ДЗ для Практикума)

Подключиться через ODBC-драйвер (как показано на занятии) к базе `otus_sa_2023_10` (сервер `46.17.248.133`) и создать «умные таблицы» на основании SQL-запросов, которые покажут:

1. Среднее количество заказанных блюд по неделям (использовать оператор `EXTRACT`).
2. Кумулятивную сумму продаж по датам.
3. Ранжирование клиентов по сумме их заказов.

Параметры подключения: PostgreSQL, сервер `46.17.248.133`, порт `5432`, база `restaurants` (в задании указана `otus_sa_2023_10` — уточнить), логин `student`. Пароль в репозиторий не записывается.

Требования:

- каждая таблица привязана к запросу, который ссылается на данные из СУБД;
- каждая таблица визуализирована диаграммой на отдельном листе Excel-файла;
- работа принимается **только в формате xlsx**.
