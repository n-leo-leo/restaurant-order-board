# Домашнее задание

## Тестовые сценарии и чек-лист

### Цель

Составить тестовые сценарии (позитивные и негативные) для критериев приёмки User Story и чек-лист проверки продукта для обеспечения качества функционала.

---

### Описание / пошаговая инструкция выполнения

Необходимо:

1. Проанализировать User Story, декомпозированные в рамках предыдущего ДЗ, и их критерии приёмки.
2. Минимум для трёх критериев приёмки описать тестовые сценарии (позитивный, 2–3 негативных), используя техники тест-дизайна.
3. Составить чек-лист для проверки продукта (5–7 пунктов).

Задание выполняется индивидуально и сдаётся в виде ссылки на документ Google Doc или на страницу в базе знаний (например, Confluence / Notion / Yonote) с перечнем задач.

---

### Критерии оценки

1. Подготовлено минимум 3 сценария тестирования.
2. Для каждого сценария тестирования указаны базовый, альтернативный, негативный варианты.

Статус **«Принято»** ставится при соблюдении всех критериев.
