# Домашнее задание  
## Доработка Use Case

### Цель

Отработать навыки создания и детализации диаграммы Use Case и описания пользовательского сценария для решения задач системного анализа.

---

### Описание / пошаговая инструкция выполнения

Необходимо:

1. Завершить диаграмму Use Case, начатую на вебинаре (учесть комментарии + возможно внести собственные правки относительно работы в группе).
2. Детально описать сценарий для одного из вариантов использования: «Оформить заказ», «Отменить заказ», «Настроить состав меню» или «Настроить технологическую карту».

Задание выполняется индивидуально. Для сдачи работы отправьте преподавателю следующие файлы:

- схему в формате `.jpg` или `.png` в высоком разрешении;
- один исходник (например, в формате `.bpmn`).

---

### Критерии оценки

1. Подготовлена Use Case по описанному в материалах кейсу.
2. На Use Case диаграмме отражено не менее 5 сценариев (акторы, use cases и связи выделены и нарисованы корректно).
3. Описан хотя бы один основной сценарий и два альтернативных сценария для одного выбранного UC («Оформить заказ», «Отменить заказ», «Настроить состав меню» или «Настроить технологическую карту»).

Статус **«Принято»** ставится при соблюдении всех критериев.
