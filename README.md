# Робот и точка — приложение для заказа и табло выдачи

[Открыть проектную документацию](https://n-leo-leo.github.io/restaurant-order-board/)

Проектная работа по системному анализу для автоматизированного ресторана. Гость выбирает блюда в киоске, оплачивает заказ картой и получает чек и талон. Когда роботизированная кухня размещает заказ в ячейке, гость видит её номер на табло и открывает ячейку талоном. Если оплаченный заказ невозможно выдать, менеджер оформляет полный возврат через внешние системы.
